### Coursework Assignments Overview

This repository represents the complete, academically rigorous, and empirically validated laboratory submissions for the course **Programming in Java (CSA09 / CSA0921)** across all assessed Course Outcomes (CO1 to CO4):

1. **Assignment 1 – CO1: Object-Oriented Modeling & System Design**
   - **Focus:** Campus Smart-Parking System, class hierarchies, jagged arrays, constructor chaining, polymorphism, encapsulation, memory modeling.
   - **Artifact:** `SIMATS_Java_Assignment_1_Report.pdf` (35 Pages)

2. **Assignment 2 – CO2: Strings and the Java Collection Framework**
   - **Focus:** String/StringBuilder/StringBuffer benchmarking under load, ArrayList vs LinkedList operating boundaries, ArrayDeque double-ended queues, HashSet hashCode-equals identity contracts, Map trade-offs (HashMap, TreeMap, LinkedHashMap), generic ranking architectures (Comparable/Comparator), PriorityQueue triage ordering, and Day-4 Design Challenge (5-Bucket Multi-Level Queue).
   - **Artifacts:** `Assignment2/` directory, `SIMATS_Java_Assignment_2_Report.pdf`, `SIMATS_Java_Assignment_2_Report.docx`

3. **Assignment 3 – CO3: Exception Handling and Multithreading**
   - **Focus:** Robust ATM exception hierarchy, user-defined checked/unchecked exceptions and chaining, Try-With-Resources resource leak elimination, Thread lifecycle and scheduling experiments, Cinema seat-booking race conditions and atomic synchronization, Deadlock prevention via lock ordering and producer-consumer token coordination, and a concurrent fault-tolerant semester result processor.
   - **Artifacts:** `Assignment3/` directory, `SIMATS_Java_Assignment_3_Report.pdf`, `SIMATS_Java_Assignment_3_Report.docx`

4. **Assignment 4 – CO4: Event-Driven GUI Design**
   - **Focus:** GUI design review and MVC refactoring, Outpatient appointment desk event models, Library search layout resizing with nested containers, event-handling forensics and repaint persistence, comparative event styles (Frame listener, named inner class, anonymous inner class, lambdas), and a full-featured Campus Event Registration Desktop Application with Swing & JDBC.
   - **Artifacts:** `Assignment4/` directory, `SIMATS_Java_Assignment_4_Report.pdf`, `SIMATS_Java_Assignment_4_Report.docx`
